## How to actually read the colorful notes

GitHub's file browser only shows `.html` files as raw source code — it does not render them. To see the notebook-style colorful design, always open the **live site**, not the repo file view:

👉 https://vipulmanoharahuja.github.io/World-Quant-University/

Click through: Home → Degree → Subject → Module. Keeping files as `.html` (not `.md`) is what makes the colorful fonts/highlighters/formulas possible — Markdown on GitHub strips custom CSS, so a `.md` version would lose all the styling.

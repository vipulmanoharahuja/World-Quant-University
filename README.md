## In-page navigation (inside each module's notes)

- **Sticky top bar** — jumps straight to any Lesson / Reading / Cheat Sheet from anywhere on the page.
- **Index (TOC)** at the top of each module — full table of contents.
- **⬆ Index / ← Previous / Next →** links at the end of every Lesson &amp; Reading section, so you can move straight to the next section without scrolling back up.

## How to actually read the colorful notes

GitHub's file browser only shows `.html` files as raw source code — it does not render them. To see the notebook-style colorful design, always open the **live site**, not the repo file view:

👉 https://vipulmanoharahuja.github.io/World-Quant-University/

Click through: Home → Degree → Subject → Module. Keeping files as `.html` (not `.md`) is what makes the colorful fonts/highlighters/formulas possible — Markdown on GitHub strips custom CSS, so a `.md` version would lose all the styling.

## Language

All notes are written in plain English (no Hinglish) so they're easy to share with anyone, anywhere.

## Adding a new degree / university

Future universities/degrees (e.g. a PG in AI / Data Science) go alongside `Master of Science in Financial Engineering/` at repo root, with the same University → Degree → Subject → Notes structure, and get linked from the root `index.html`.
